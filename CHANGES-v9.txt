Omni Ai v9 (2.6.0): কী ঠিক করা হয়েছে
- .exe: প্রতিবার র‍্যান্ডম পোর্টের কারণে চ্যাট ও API key হারিয়ে যেত; এখন নির্দিষ্ট পোর্ট (38517) + একটাই উইন্ডো।
- Service worker: পুরনো ফাইল আটকে থাকত (cache-first); এখন network-first, নতুন ভার্সন সাথে সাথে আসে।
- নিরাপত্তা: same-host origin এখন শুধু IP ঠিকানায় (DNS-rebinding ঠেকাতে)।
- Free-limit auto-switch ফিরিয়ে আনা হয়েছে (Settings-এ টগল, ডিফল্ট চালু): শুধু ফ্রি মডেল, রিপ্লাই শুরুর আগে, সর্বোচ্চ ৪ বার, 401/403/400/policy এরর হলে সুইচ নয়।
- Connectors: অফিসিয়াল সাইট খুললেই "Connected" দেখাত; এখন "Opened (login not verified)"।
- New Folder: prompt() Electron-এ কাজ করে না; ইনলাইন ইনপুট।
- Ollama/LM Studio এখন চ্যাটবক্সের provider লিস্টে।
- ৩ বার ডুপ্লিকেট base64 ছবি বাদ, ফাইল ১২% হালকা।
- মোবাইল কম্পোজার: সেন্ড বাটন নিচে ভেঙে যেত, ঠিক করা হয়েছে।
যাচাই হয়নি: আসল Windows .exe বিল্ড, APK বিল্ড (GitHub Actions চালাতে হবে), আসল provider key দিয়ে চ্যাট।
