AI ENGINE: কীভাবে চালাবেন (ধাপে ধাপে)
=====================================

একবারের কাজ: Node.js ইন্সটল
--------------------------------
1. https://nodejs.org খুলুন।
2. সবুজ "LTS" বাটনে ক্লিক করে ফাইলটা ডাউনলোড করুন।
3. ফাইলটা খুলে Next > Next > Install করুন (কিছু পরিবর্তন করার দরকার নেই)।
4. ইন্সটল শেষ হলে কম্পিউটার রিস্টার্ট করার দরকার নেই, তবে কোনো খোলা টার্মিনাল থাকলে বন্ধ করে দিন।

AI Engine চালানো (Windows)
--------------------------------
1. ai-engine.zip ফাইলে ডান ক্লিক করে "Extract All" করুন। (Zip-এর ভেতর থেকে সরাসরি চালাবেন না, আগে Extract করতে হবে।)
2. Extract হওয়া ai-engine ফোল্ডার খুলুন।
3. start-windows.bat ফাইলে ডাবল ক্লিক করুন।
   - নীল রঙের "Windows protected your PC" দেখালে: "More info" > "Run anyway" চাপুন।
4. একটা কালো উইন্ডো খুলবে আর ২ সেকেন্ডের মধ্যে ব্রাউজারে AI Engine খুলে যাবে।
   না খুললে ব্রাউজারে লিখুন: http://localhost:3000
5. ব্যবহার শেষ হলে কালো উইন্ডোটা বন্ধ করে দিন।
   (কালো উইন্ডো খোলা না থাকলে AI Engine চলবে না।)

AI Engine চালানো (Mac / Linux)
--------------------------------
1. Zip Extract করুন।
2. Terminal খুলে ফোল্ডারে যান আর লিখুন:  sh start-mac-linux.sh

প্রথমবার API key বসানো
--------------------------------
চ্যাট করতে প্রতিটি provider-এর নিজের API key লাগে। সবচেয়ে সহজ শুরু:

1. https://openrouter.ai/keys এ গিয়ে অ্যাকাউন্ট খুলুন ও একটা key বানান (ফ্রি)।
2. AI Engine-এ বাঁ দিকের নিচে "API keys" বাটনে ক্লিক করুন।
3. OpenRouter-এর ঘরে key পেস্ট করুন।
4. বাঁ দিকে "Free models" ক্লিক করুন, যেকোনো "FREE" ট্যাগ করা মডেল বেছে নিন।
5. নিচের বক্সে মেসেজ লিখে Enter চাপুন।

পেইড মডেল বা অন্য provider (NVIDIA, MiniMax, DeepSeek ইত্যাদি) চালাতে সেই provider-এর key একই জায়গায় বসাতে হবে।
প্রতিটির পাশে "Get key" লিংক আছে, সেখান থেকে key বানানো যায়।

সমস্যা হলে
--------------------------------
- "Node.js is not installed" দেখালে: উপরের "Node.js ইন্সটল" ধাপটা করুন, তারপর আবার চালান।
- "Cannot reach the AI Engine server" দেখালে: কালো উইন্ডোটা খোলা আছে কি না দেখুন। না থাকলে start-windows.bat আবার চালান।
- "port already in use" দেখালে: আগের কালো উইন্ডো আরেকটা খোলা আছে। সেটা বন্ধ করুন।
- কোনো মডেল এরর দিলে: সেই provider-এর key ঠিক আছে কি না আর অ্যাকাউন্টে ব্যালান্স আছে কি না দেখুন।
